# RentLedger — Client

React + Vite frontend for the RentLedger rental management app.

## Setup

```bash
npm install
npm run dev
```

Runs at `http://localhost:5173`. Make sure the server is running at `http://localhost:5000`.

## Pages

| Route | Page |
|-------|------|
| `/` | Landing |
| `/login` | Login |
| `/register` | Register |
| `/dashboard` | Dashboard |
| `/properties` | Properties |
| `/tenants` | Tenants |
| `/leases` | Leases |
| `/payments` | Payments |
